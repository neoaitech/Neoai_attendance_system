# VisionAttend Deep Learning Models

Stores pre-trained neural network weights for computer vision inference.

- `yolo/yolov8n-face.pt`: YOLOv8-Face object detection model for robust classroom multi-face localization.
- `arcface/arcface_w600k_r50.onnx`: ResNet-50 ArcFace ONNX model generating 512-D normalized unit embeddings.
