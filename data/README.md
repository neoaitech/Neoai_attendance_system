# VisionAttend Data Directory

Stores uploaded assets, facial crops, and generated reports.

- `uploads/students/`: Multi-angle reference enrollment photos for registered students.
- `uploads/sessions/`: Raw and annotated panoramic classroom attendance photos.
- `uploads/unknown_faces/`: Unmatched facial crops queued for manual verification.
- `reports_cache/`: Cached attendance spreadsheets (.xlsx) and PDF audit reports.
